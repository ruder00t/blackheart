Blackheart — Contents

The collection:

  • Variables & home (the shared values that feed every command), Wordlists, and OSINT (tools, live web resources, image intel).
  • Nmap builder (assemble an nmap command from options)
  • CheckMap (turn an nmap scan into per-host service checklists)
  • VersionCheck (check for outdated versions from WhatWeb or an nmap scan)
  • Exploitation (SQLi, XSS, SSTI, XML, API, CMS/WordPress, Wireless, File Upload, and a full Active Directory attack-path playbook — tabbed by access level, ESC1–ESC15, coercion, SCCM, trusts, with the OCD mindmap bundled offline)
  • Access (Reverse shells — now with a Webshells subchapter (PHP/ASPX/JSP, Antak, Laudanum, tunnelers) — and Listeners)
  • Privilege Escalation (Windows, Linux, Mac, Automation, plus offline GTFOBins and LOLBAS)
  • Post-exploit (Pivoting, Pillaging, Persistence, File transfer)
  • Reference (HackTricks (offline copy), Cracking (hashcat/John + custom wordlists: username-anarchy, CUPP), Day0 (fresh install))
  • Decode (offline CyberChef + hash identifier), JWT (decode, verify, sign, attacks) and Cmd Obfuscator
  • Libraries (Command Library, Tool library, Script library)
  • CVSS Calculator (v3.1 base + temporal score, severity, copyable vector string)
  • Report Builder (fill in a Markdown report, theme it, export a standalone PDF)
  • Additions overlay (pin your own notes onto any tab, with import and export functionality)
